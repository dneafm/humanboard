Workflow selection checklist

Green light
  • Visible inputs and outputs
  • Repeated work + human review
  • Daily or weekly pain
  • Costly errors
  • Digital trace across tabs/spreadsheets/chat
  • Measurable improvement + fallback stays alive
Yellow light
  • Physical work with strong digital shadow
  • Closed tools with CSV/export/browser access
  • Messy handoffs but clear outcomes
  • Weak docs but real repeated pain
  • Proceed only if state, decisions, exceptions, outcomes are observable
Red light
  • Mostly physical workflow with weak digital trace
  • Closed app with no API/export/browser/reporting path
  • Unclear ownership
  • Rare one-off tasks
  • Unmeasurable improvement
  • Huge downside with weak verification
